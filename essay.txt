forEach() is an array method used to execute a function for each element in an array. It is useful when you simply want to perform an action on every element in the array.

for  of is a loop used to iterate over the values of iterable objects such as arrays, strings, and more and it is more flexible because you can use break, continue, and return inside it.

ex :
let arr = [1, 2, 3];

arr.forEach(num => {
    console.log(num);
});

for (let num of arr) {
    console.log(num);
}

you forEach() when you want to perform an action on every array element and don't need to stop the loop early.
you for  of when you need more control over the loop like using break or continue.

-Q5 :
Type conversion: When the programmer manually changes a value from one data type to another.
Type coercion: When JavaScript automatically changes the type of a value when performing an operation.

ex:

Type Conversion:

let str = "123";
let num = Number(str);

console.log(num); // here the output is 123 as a number 
=========================================================
Type Coercion:

let result = "5" + 2;

console.log(result); // "52" as a string
